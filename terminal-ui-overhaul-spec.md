1. Principles and anti-goals
- Terminal first, not costume. Prompt line with caret, mono labels, status line, command palette on every screen. Serif display (Fraunces) is Shipped on H1s and wordmark and stays: rule is serif-display-only, never for labels, inputs, status, or paths. A future different-terminal direction may swap the display face, but the display-only boundary holds either way.
- One accent flat hairlines. Accent is ember C7431F Shipped, flat paper surfaces, 1px hairlines between regions. Focus ring is 3px solid ember offset 2px Shipped, keyboard-only, meeting 3 to 1 on both canvases; v3 double-ring blue proposal is withdrawn. Violation list, extended with competitor bans: gradients, glassmorphism, neon glow, shadows beyond modal, parallax, scroll-jacking, autoplay, bounce springs, decorative background text that harms contrast (Cloudflare marketing faded sitemap), logo strips at illegible size (Agent Router 16-logo strip), badge confetti without date and live status (Helicone YC/POTD), stock 3D beside a precise diagram (Inference Gateway cloud art), cinematic hero for a dense workbench (MLflow discontinuity), pastel wash collapsing to void (LiteLLM full-page), rebrand headlines burying value (Portkey PRISMA takeover), consent plus chat plus promo stacked (TrueFoundry triple overlay), floating chat FABs over output (UniteRouter, IBM, Gravitee docs), promo banners pushing status down (Azure Ignite), duplicate CTAs and duplicate AI entries, mid-task rating widgets (AWS/Gravitee Was this helpful), second stacked consent toasts (Gravitee double banner), Extras buckets hiding functionality (TrueFoundry docs), beta labels without capability deltas (LangDB K8s/GCP beta), double global headers burying auth (API7 commercial plus docs nav pushing content 120px), interleaved Concepts with Tasks at one level (Cloudflare docs Header Glossary beside guides), intermixed modalities SDKs tasks as siblings (Vercel sidebar Text beside AI SDK beside OpenAI Responses), fake output never (radlab rule: every transcript line maps to a real CLI verb).
- Keyboard first. Tab order matches visual order, Ctrl+K palette global, Ctrl+Enter send, R retry probe, slash focuses filter when not in text input, Escape closes topmost layer, arrows move in lists and palette. Focus ring keyboard-only, targets 44px primary and 32px minimum secondary with spacing to reach 24px effective.
- Mirror themes. Same spacing borders layout, tokens flip only.
- Empty as prompt, error as diagnosis. Empty trio is status line plus learning cue plus direct action with key hint. Error block is cause plus what was tried plus next action with retry, endpoint path mono, HTTP status, one-line last error, countdown where polling. Numeric errors show attempted path plus 3 likely intents ranked by edit distance, never random popular pages (OpenRouter 404 anti-lesson). Assistant prompt stays available on every error screen (OpenRouter Ask Assistant persistence).
- Accessibility and performance are launch gates, not polish.
